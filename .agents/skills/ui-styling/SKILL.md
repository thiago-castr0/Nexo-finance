# UI Styling (`ui-styling`)

Consulte também `Skills/skill_ui_styling.md` (`UIE-003`).

## Regras Principais
1. **Pareamento 500 / 200 / 100:** Usar o nível `500` para texto/ícone/borda ativa, `200` para bordas suaves e `100` para fundos de hover e badges.
2. **Escala Neutra:** `#09090B` (Black), `#18181B` (Gray 900), `#3F3F46` (Gray 700), `#71717A` (Gray 500), `#D4D4D8` (Gray 300), `#E4E4E7` (Gray 200), `#F4F4F5` (Gray 100), `#FFFFFF` (White).
