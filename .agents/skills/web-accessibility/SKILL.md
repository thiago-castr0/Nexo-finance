# Web Accessibility (`web-accessibility`)

Consulte também `Skills/skill_web_accessibility_a11y.md` (`UIE-004`).

## Regras Principais
1. **Navegação por Teclado:** Ordem lógica de `Tab` em formulários, tabelas de rascunho e filtros.
2. **Feedback Semântico:** Uso de `role="status"`, `role="alert"`, `aria-invalid` e `aria-describedby`.
3. **Independência de Cor:** Combinar cor semântica (`#0CB853` / `#DF2929`) com sinais `+`/`-` e ícones Lucide.
