# Impeccable UI (`impeccable`)

Consulte também `Skills/skill_impeccable_ui.md` (`UIE-002`).

## Regras Principais
1. **Camadas de Superfície:** Fundo `#F4F4F5` (Light) / `#09090B` (Dark) com superfícies `#FFFFFF` / `#18181B` e bordas finas `1px solid #E4E4E7`.
2. **Precisão Óptica:** Ícones Lucide com `strokeWidth={1.5}` alinhados perfeitamente à tipografia Inter e numerais tabulares.
3. **Microinterações:** Preenchimento sutil nível `100` no `hover` e transições suaves de `150ms`.
