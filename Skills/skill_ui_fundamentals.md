# Skill: Fundamentos de UI e Design Visual
**Descrição:** Aplica os conceitos basilares de design de interface para criar telas limpas, profissionais e esteticamente agradáveis, focadas em conversão e leitura de dados financeiros.

## Regras de Execução:
1. **Hierarquia Visual:** Usar tamanho, peso da fonte e cor para guiar o olhar. O Saldo Total deve ser o elemento de maior destaque, seguido de Receitas/Despesas.
2. **Espaçamento e Respiro (White Space):** Aplicar múltiplos de 4px ou 8px (padrão Tailwind) para garantir respiro entre os cards do Dashboard.
3. **Tipografia:** Utilizar fontes sem serifa modernas e legíveis (ex: Inter ou Roboto). Números (valores financeiros) devem usar fontes monoespaçadas ou numerais tabulares para alinhamento perfeito em tabelas.
4. **Psicologia das Cores:** Usar cores semânticas padrão (Verde para entrada, Vermelho para saída), mas em tons pastéis ou dessaturados no Dark Mode para não cansar a vista.
5. **Consistência:** Garantir que botões primários, secundários e ghost tenham a mesma aparência em toda a aplicação.
